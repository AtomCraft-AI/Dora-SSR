## 服务与组件

`Theme` 管理颜色与圆角；`Controls` 复用按钮；`Visual.SceneSurface` 按原生场景顺序绘制前景及弹层，避免 NanoVG 背景绘制覆盖关系造成的问题；`Cartridge` 和 `GestureGuide` 独立绘制卡带、插槽及非模态引导。

`Feed` 继续使用现有目录、安装和项目创建回调。发现只循环真实目录中的作品，不显示本地计数。缺少作者数据时不生成虚构作者。新建先打开内存中的草稿会话；第一条非空提示词且模型配置可用时，才使用现有 TypeScript 空项目模板创建目录与会话。空输入、未配置模型或直接返回均不创建目录，失败重试复用已创建的项目。尚未生成游戏的空项目禁用 GO!。

`Remix` 保留会话、执行/计划、问卷、模型选择与停止任务服务。聊天滚动不显示滚动条；用户阅读历史时收到新消息会保留位置。横屏问卷内容独立滚动，底部操作固定。

`WorkspacePanel` 按需展开文件、代码、修改记录、日志和设置。代码草稿在当前会话内保留；保存经过 `applyFileChanges` 检查点服务并构建支持的脚本。保存前比较磁盘基线，发现外部修改时保留草稿并提供显式重新载入。Agent 工作或 Web IDE 接管时禁止写入；回退先确认，再恢复检查点并重新构建。构建失败时禁止直接试玩，避免运行旧的编译产物。

项目名称是按工作目录保存的本地显示名称，不移动目录或改动导入路径。导出继续使用现有项目打包服务。`Entry` 从会话启动试玩时保留会话宿主，退出试玩后恢复对话、输入和滚动状态。

## 可重复检查

已有 `Tools/dora-dora/node_modules` 后，在仓库根目录运行：

```powershell
node Tools/build-scripts/check_go_ui.cjs --write
node Tools/build-scripts/check_go_ui.cjs
```

该脚本使用 Web IDE 内的同一 TS-to-Lua 编译器；检查 Mobile 类型、导航/会话状态断言和 17 个修改模块的 TS/Lua 一致性。`Entry.yue` 通过原生 WebServer 的 `buildAsync` 编译，生成的源码标头保持 `Script/Dev/Entry.yue`。

## 简介与 Agent 配置

简介收起时为一行省略文本；展开时信息区和卡带平滑上移，作者操作行保留位置。展开区按真实字体度量显示三行，超出内容在区内独立滚动，点击正文或箭头均可收起并恢复原布局；正文拖动仅滚动，不收起。

首页齿轮与会话页共享 Agent 配置抽屉。底层页面保持可见，浅色遮罩拦截操作；配置列表连续滚动，保留当前选择、编辑 API Key 和添加配置入口，右上角可关闭。弹层复用淡入上移与关闭过渡，并尊重系统减少动态效果设置。

`Tools/tests/go-ui-revision/init.lua` 检查延迟创建、空输入、缺少模型配置、项目与会话创建失败重试、简介展开/滚动、卡带缩放回弹、配置面板背景保留和窄屏/横屏视口。执行方式同动效检查，结果写入可写目录 `go-ui-revision/`。所有模型提交使用测试适配器；不调用真实模型服务。

Windows 原生复验：43 项草稿/简介/配置检查、22 项动效检查、24 项导航/会话/文件回归均通过；17 个 Mobile 模块通过类型与 Lua 一致性检查。配置面板已检查 320×640、390×844 和 844×390 逻辑尺寸。

会话标题右侧使用 Lucide 铅笔图标进入原位编辑，移除三点项目设置入口。标题替换为单行输入框，右侧叉号取消、勾号确认；编辑时暂时让出 GO! 按钮的位置，完成后恢复。取消保留原名称，确认保存显示名称；空名称与未完成的中文输入不提交，会话刷新保留正在输入的节点。草稿改名不创建项目目录。共享底部弹层只保留顶部圆角。

## 会话滚动与试玩诊断

纵向滚动不再设置横向导航锁；横向手势丢失松手事件时，500ms 无移动后恢复页面位置和状态轮询。会话正在拖动时延后轮询与布局更新，松手后继续；滚动触摸状态同样有失效恢复，避免界面一直保留“正在创作”。置底按钮只在显隐变化时更新，消息节点使用索引复用，减少滚动和会话更新开销。

`Tools/tests/go-ui-scroll/init.lua` 包含 6 项原生断言，检查纵向/横向手势丢失松手、位置恢复、消息到达保留阅读位置、连续滚动及置底。通过正在运行实例的 `/command` 执行 `dofile`，结果写入可写目录 `go-ui-scroll/results.txt`；不会提交模型请求。调试已有会话时使用此方式，避免 `cli run` 清理当前运行场景。

Windows 的 Agent TypeScript 编译目前仍依赖连接的 Web IDE，Android 使用内置编译桥。任务状态为 DONE 不代表编译成功：编译返回 `Web IDE not connected` 时，新项目可能仍保留空 Lua 模板，GO! 会保持不可用。当前项目已使用仓库同源编译器补编译，并验证 GO! 启动与返回会话；此操作没有改变 Windows 编译依赖。
