# Pattern: Interactive Visualization

## Use When

Understanding depends on seeing how a representation changes with a parameter, transformation, structure, or time.

## Core Loop

Manipulate → observe linked representations → compare → predict → test → explain.

## Design Rules

- Keep the manipulable control near the affected representation.
- Update all linked views synchronously.
- Provide reference markers, scale, units, labels, or coordinates when needed.
- Allow snapshot/compare-two-states when relationships are the learning target.

## Good Uses

Function parameters, geometry, vectors, ray diagrams, molecular models, anatomy structures, plate motion, music notation-to-sound.

## Avoid

Decorative movement with no inspectable relationship or controls whose visual outcome is ambiguous.
