# Pattern: Dialogue Role-Play

## Use When

Learning requires communication, perspective-taking, interviewing, negotiation, explanation, or applying rules in a social scenario.

## Core Loop

Role/context → goal → choose/produce response → counterpart reacts → inspect meaning/effect → revise/continue.

## Design Rules

- Give each role a clear objective and relevant information.
- Feedback should explain why a response worked or failed in context.
- Support multiple valid phrasings/strategies when appropriate.
- For civics/ethics, do not score partisan positions; score reasoning, evidence, process, or rule application.

## Good Uses

Language practice, historical perspective, safety decisions, stakeholder negotiation, oral communication.
