# Pattern: Inquiry Learning

## Use When

The learning objective is discovering a relationship, evaluating a hypothesis, or learning how evidence supports a conclusion.

## Core Loop

Question → prediction/hypothesis → choose evidence/variables → run/inspect → record → compare → revise explanation.

## Design Rules

- Make the variable being tested explicit.
- Encourage one-variable-at-a-time comparison when causality is the goal.
- Record trials so learners can compare rather than rely on memory.
- Ask for a prediction before revealing the outcome when practical.

## Teacher Features

Preset inquiry questions, lockable variables, revealable conclusion, class comparison table.

## Avoid

“Discovery” where the answer is shown first, or experiments that cannot distinguish competing explanations.
