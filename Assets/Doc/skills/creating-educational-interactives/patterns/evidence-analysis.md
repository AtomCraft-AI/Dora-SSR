# Pattern: Evidence Analysis

## Use When

Students must support claims using text, sources, images, data, artifacts, or observations.

## Core Loop

Inspect source → mark/collect evidence → classify/compare → make claim → attach evidence → receive reasoning feedback → revise.

## UI Elements

Source pane, evidence cards/highlights, claim workspace, relation arrows/tags, source metadata when relevant, compare view.

## Feedback

Distinguish evidence relevance, reliability, sufficiency, and inference. A plausible claim without evidence is incomplete; evidence without explanation is also incomplete.

## Good Uses

Close reading, history sources, civics cases, scientific result interpretation, visual art analysis.
