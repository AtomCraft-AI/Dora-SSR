# Pattern: Virtual Lab

## Use When

The learner must perform or investigate an experiment/procedure where variables, apparatus, observations, measurement, or safety matter.

## Core Loop

Question/prediction → configure apparatus/conditions → perform action → observe phenomenon → measure/record → compare → explain → retry/free explore.

## Required State

Define apparatus state, controllable variables, measurement data, procedural state, result state, and reset behavior. Controls must change the simulated result rather than select a prerecorded animation.

## Teacher Features

Pause, step, reset, compare trials, show/hide labels and model view, lock/unlock variables, clear records.

## Feedback

Differentiate conceptual error, setup/procedure error, measurement error, and result interpretation. Explain how the mistake changes evidence.

## Completion

Experiment record, comparison chart, calculated result, evidence-based conclusion, or error analysis.
