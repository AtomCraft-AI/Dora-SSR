# Pattern: Teacher Orchestration

## Use When

The application is primarily a live classroom demonstration or teacher-led inquiry.

## Required Controls

- start/pause/step/reset
- hide/reveal labels, answer, explanation, trajectory, model layer, or annotation as appropriate
- quick parameter presets
- compare previous/current trial
- clear workspace/history
- guided task mode and free exploration when useful

## Classroom UI

Make the current question, main phenomenon, and key variable readable from a distance. Avoid tiny controls and dense sidebars. Put advanced controls behind a secondary panel.

## Teaching Sequence

Prompt prediction → run/manipulate → pause on evidence → ask class → reveal/annotate → compare → summarize.

## Avoid

Auto-playing through the entire explanation without giving the teacher moments to stop and ask questions.
