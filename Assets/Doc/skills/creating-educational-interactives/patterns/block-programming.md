# Pattern: Block Programming

## Use When

Students learn programming logic by constructing executable blocks.

## Core Loop

Read task → assemble blocks → predict → run → highlight execution → inspect failure/state → debug → optimize.

## Required Features

Block palette, workspace, executable target/world, run/pause/reset, current-block highlight, visible variables/sensors when relevant, single-step mode for debugging.

## Progression

Sequence → repeat → condition → event/state → variables → custom blocks/functions → composition/optimization.

## Feedback

Point to execution symptom and step before suggesting a construct. Example: “At step 7 the robot sees an obstacle but no conditional branch handles it.”

## Avoid

Moving the actor independently of blocks, auto-correcting programs invisibly, or revealing the final solution immediately.
