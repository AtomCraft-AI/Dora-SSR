# Pattern: Creation Studio

## Use When

Learning is demonstrated by making, testing, revising, or explaining an artifact.

## Core Loop

Brief/constraints → create → preview/test → inspect criteria → revise → compare versions → explain choices.

## Design Rules

- Give a meaningful constraint set, not a blank canvas unless free creation is the goal.
- Keep tools directly related to the learning concept.
- Preserve versions or before/after comparison when revision matters.
- Critique against explicit criteria while allowing multiple valid solutions.

## Good Uses

Engineering design, geometric construction, art composition, writing, music patterns, data visualization, interdisciplinary projects.
