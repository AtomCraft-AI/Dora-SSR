# Pattern: Assessment & Feedback

Assessment is a supporting layer, not the default core interaction.

## Feedback Ladder

1. **Outcome:** what happened.
2. **Location/state:** where the issue appeared.
3. **Conceptual hint:** what relationship/rule to reconsider.
4. **Strategic hint:** a next experiment or comparison.
5. **Worked explanation:** only after need is established or explicitly requested.

## Better Evidence Than Multiple Choice

Prefer prediction, manipulation, construction, ordering, evidence selection, debugging, explanation, or transfer to a new case.

## Teacher Use

Provide a compact result summary: task completed, key misconception, number/type of retries, final artifact/result. Avoid pseudo-precise “AI mastery scores” without a defensible model.
