# Pattern: Narrative AVG

## Use When

Learning depends on perspective, sequence, motives, interpretation, communication, or constrained decision-making within a narrative context.

## Core Loop

Context → inspect dialogue/details → make/compare a choice → observe consequence or alternative → return to evidence/canonical line → explain.

## Design Rules

- Narrative choices must reveal a concept, perspective, or consequence.
- In literature/history, visually label hypothetical branches.
- Preserve a route back to source/canonical events.
- Collect evidence from scenes rather than treating choices as personality tests.

## Good Uses

Literary character analysis, historical perspective, ethics cases, language role-play.

## Avoid

Invented plot presented as source material, arbitrary good/bad endings, or long passive dialogue without meaningful inspection or choice.
