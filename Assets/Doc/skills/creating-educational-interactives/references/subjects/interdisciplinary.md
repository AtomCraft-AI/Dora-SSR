# Interdisciplinary / Project-Based Learning

Use only when the learning goal genuinely requires integrating methods or evidence from multiple disciplines.

## Learning Actions

Frame a problem, gather evidence, build a model or artifact, test trade-offs, revise, and communicate a justified solution.

## Strong Patterns

- [Creation studio](@agent-skill/builtin/creating-educational-interactives/patterns/creation-studio.md)
- [Inquiry learning](@agent-skill/builtin/creating-educational-interactives/patterns/inquiry-learning.md)
- [System simulation](@agent-skill/builtin/creating-educational-interactives/patterns/system-simulation.md)

## Design Rules

- State which subject contributes which method or evidence.
- Give a concrete product or decision target: design a low-energy classroom, plan a flood-resilient neighborhood, build a museum exhibit, create an ecological monitoring plan.
- Avoid “interdisciplinary” meaning merely answering questions from several subjects in sequence.
- Trade-offs must be visible and grounded in the contributing disciplines.

## Completion Evidence

A tested artifact, system proposal, annotated model, evidence-backed recommendation, or presentation with traceable reasoning.

## Avoid

Scope explosion. Prefer one integrated problem with a few meaningful constraints over a giant “everything” project.
