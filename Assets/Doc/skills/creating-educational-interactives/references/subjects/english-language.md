# English / Foreign-Language Learning

## Learning Actions

Understand meaning, choose language for a purpose, listen/read for information, negotiate a task, produce language, receive corrective feedback, and try again.

## Strong Patterns

- [Dialogue role-play](@agent-skill/builtin/creating-educational-interactives/patterns/dialogue-roleplay.md)
- [Evidence analysis](@agent-skill/builtin/creating-educational-interactives/patterns/evidence-analysis.md) for reading/listening
- [Creation studio](@agent-skill/builtin/creating-educational-interactives/patterns/creation-studio.md) for writing/speaking planning

## Design Rules

- Design around communicative intent: ordering food, asking directions, interviewing, persuading, describing, summarizing.
- Match vocabulary and grammar complexity to stage.
- Feedback should distinguish meaning, grammar, word choice, and appropriateness when relevant.
- Allow multiple valid phrasings instead of a single memorized sentence when the task is communicative.
- Use scaffolds such as phrase banks, sentence frames, or optional translation progressively, not permanently.

## Student Progression

Model → guided choice → partial production → freer production → reflection/revision.

## Avoid

Punishing harmless variation, equating accent with correctness, or making vocabulary collection the main game while communication remains absent.
