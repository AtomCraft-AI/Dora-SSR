# Information Technology & Programming

## Learning Actions

Construct, execute, trace, predict, debug, refactor, optimize, and explain programs or digital systems.

## Strong Patterns

- [Block programming](@agent-skill/builtin/creating-educational-interactives/patterns/block-programming.md)
- [System simulation](@agent-skill/builtin/creating-educational-interactives/patterns/system-simulation.md)
- [Creation studio](@agent-skill/builtin/creating-educational-interactives/patterns/creation-studio.md)

## Design Rules

- Execution state must be visible: highlight the current block/statement and show relevant variables.
- Errors should identify symptom and location before suggesting a fix.
- Introduce abstraction because repetition creates a need: loops, functions/custom blocks, data structures.
- Prefer tasks with multiple valid solutions; compare efficiency only after correctness.
- For networking/data topics, visualize flow and state without inventing technical behavior.

## Progression

Sequence → loop → condition → events/state → variables → functions/custom blocks → composition/debugging/optimization, adjusted to stage.

## Avoid

A character moving independently of the student's code, hidden execution rules, “syntax trivia” as the main activity, or revealing the final program immediately after the first failure.
