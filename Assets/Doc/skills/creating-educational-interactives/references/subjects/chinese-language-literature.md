# Chinese Language & Literature

## Learning Actions

Read closely, inspect language, compare perspectives, reconstruct sequence, identify evidence, infer character/motive, analyze rhetoric/structure, and create/revise text.

## Strong Patterns

- [Narrative AVG](@agent-skill/builtin/creating-educational-interactives/patterns/narrative-avg.md) for perspective and character decisions
- [Evidence analysis](@agent-skill/builtin/creating-educational-interactives/patterns/evidence-analysis.md) for close reading
- [Creation studio](@agent-skill/builtin/creating-educational-interactives/patterns/creation-studio.md) for writing/revision

## Design Rules

- Keep **original/canonical content**, **interpretation**, and **hypothetical branch** visibly distinct.
- If using alternate choices in a classic work, return to the canonical plot and compare consequences.
- Require claims about characters/themes to cite a textual detail, scene, diction choice, or structural clue.
- For language mechanics, let students edit/reorder/compare actual sentences or passages rather than answer detached definitions only.

## Teacher Mode

Offer revealable annotations, perspective switching, evidence-card collection, theme/character relation maps, and discussion prompts.

## Copyright

Use public-domain texts where appropriate. For copyrighted modern works, avoid reproducing long passages; summarize and use brief excerpts only when justified.

## Avoid

Turning literature into plot trivia, treating one interpretation as unquestionable when evidence supports alternatives, or presenting invented dialogue as original text.
