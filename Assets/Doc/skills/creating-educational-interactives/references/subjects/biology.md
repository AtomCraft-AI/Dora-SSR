# Biology

## Learning Actions

Explore structure-function relationships, trace dynamic processes, classify evidence, model populations/ecosystems, predict inheritance, and compare interventions or environments.

## Strong Patterns

- [System simulation](@agent-skill/builtin/creating-educational-interactives/patterns/system-simulation.md)
- [Interactive visualization](@agent-skill/builtin/creating-educational-interactives/patterns/interactive-visualization.md)
- [Inquiry learning](@agent-skill/builtin/creating-educational-interactives/patterns/inquiry-learning.md)

## Design Rules

- Connect levels of organization carefully: cell → tissue → organ → organism → population/ecosystem.
- Use time controls for processes such as cell division, circulation, photosynthesis, population change.
- For genetics, make genotype/phenotype assumptions explicit and avoid implying all traits follow simple Mendelian inheritance.
- For ecosystems, show delayed and indirect effects rather than only immediate score changes.

## Feedback

Ask learners to explain a functional consequence or predict the next state before revealing it.

## Avoid

Teleological explanations (“organisms changed because they needed to”), scale confusion, or deterministic claims for probabilistic biological outcomes.
